## 1. Evidence available

- Historical results: 57 JSON files in `results/` with aggregate metrics only (macro-F1, accuracy, ECE, latency). **Per-example predictions were not saved** in the original study, so historical numbers cannot be recomputed from predictions, bootstrapped or re-calibrated. Every analysis in the paper uses new runs with saved predictions; historical values are kept as a separate, unverified layer.
- Historical ECE used 10 bins and, for the Baseten and OpenAI APIs, the API `confidence` field when present, not the probability of the predicted class. This is a methodological defect; new runs use the renormalised probability distribution and 15 bins.
- No git repository existed: the baseline was committed on 2026-10-24 before any change.

- The six training/normal-test generators were separate Claude Sonnet sub-agents, each assigned four classes (confusable classes were grouped together within one agent). They shared the same prompt template and the same label specification, so they are **not statistically independent generators**: train and normal test come from the same generators, split at random per class (40 test, up to 70 train).
- The first data-group agent initially received a prompt with an unreplaced placeholder; it stopped without writing data and was re-instructed with its four classes (see the later message in its file).
- The lexical-stress set was written by three further Sonnet agents (15 confusable pairs, 20 messages per side) and labelled blind by two validators (Claude Opus and Claude Sonnet). Agreement is between models, not human gold.

Generated stress messages: 602; validator agreement with generator labels: 99.8%, 100.0%. Excluded cases (any validator disagreeing): 1.

## 6. Claims in the original report that must change

- '~4,500 test messages' → 3,557 (historical tests).
- '0.940 vs 0.935: the small model wins' → 'higher observed score'; the difference is within test-sample noise until shown otherwise (paired bootstrap).
- 'Descriptions matter more than the model' (inferred from Banking77 vs Ottavo) → must be measured on the same messages (E03); the new N vs D runs do this.
- 'Elephant-1 and Qwen3-8B differ only in training' → false: different base model (Qwen3.5-9B vs Qwen3-8B), hybrid attention, block-bidirectional mask, Brier-term objective (E04).
- '5-shot collapse' of Qwen3 was produced by one untuned recipe (34 epochs, OneCycle, seed 0); it is a property of that recipe until the corrected recipe shows otherwise (E02).
- 'Robustness' of the adversarial set → 'lexical stress set', same task and generators; not general robustness.
- Costs: 'Elephant/Mammoth free' was promotional access, not a production price; 'cents of electricity' had no measurement behind it. ECE values of API systems were computed on the `confidence` field (see §1).
- 'Distillation removes the labelling cost' was a proposal, never tested.
